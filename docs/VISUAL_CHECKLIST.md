# Ручная визуальная проверка интерфейса

В текущей Codex-сессии инструмент браузера отсутствует. `npm run build` и отдача собранной страницы через FastAPI проверены; рендер и клики на реальном экране требуют этого прохода.

Откройте `http://127.0.0.1:8000` на Mac при ширине окна около 1440, 1024 и 390 px:

1. «Обзор»: Score, четыре severity, топ аккаунтов, категории, политика и история не перекрываются иллюстрацией; нет горизонтальной прокрутки всей страницы.
2. «Подключение»: домен, DC, reader, read-only, статус и время последней проверки читаются; кнопка показывает «Проверяем…», затем результат. Пароля нет.
3. «Запустить анализ»: кнопка блокируется на время запроса, статус запуска виден, после завершения обновлены длительность и количество объектов.
4. «Риски»: примените каждый фильтр, поиск и сортировки Risk Score/severity/username/активность/пароль. При нулевом результате видно пустое состояние. Таблица прокручивается внутри блока на узком экране.
5. Откройте `ir-domainadmin`: длинный DN/названия групп не ломают карточку; `Domain Admins` имеет Critical и объяснение области прав.
6. Откройте `ir-svc-backup`: вложенный путь виден целиком, `IR-Lab-Admins` обозначен как право только на test OU; интерактивный вход — «Не оценён».
7. «Политика домена»: видны все восемь параметров; при отсутствии значения показано «Нет данных», нули не скрыты.
8. CSV открывается в Excel с русскими буквами в отдельных колонках, без пароля.
9. Проверьте Tab/Enter по меню и строкам таблиц, состояние ошибки при недоступном LDAP и адаптивность на 390 px.
